שלב 2: הגדרות מפורטות ב-Typhoon Schematic Editor (TSE)

קונפיגורציית פרמטרי המודל, רכיב Serial Setup ורכיב Serial Receive.

2.1 הגדרות קובץ המודל (Model Configuration Properties)

  • פתיחת חלון הגדרות המודל (Model -> Configuration Properties או מקש קיצור Ctrl+E).
  • מכשיר היעד: hil_device = "HIL404"
  • מספר ליבות הסימולציה: hil_configuration_id = 1 (לניצול מלא של 4 הליבות ב-HIL 404).
  • זמן צעד הסימולציה: simulation_time_step = 1e-6 ($1\,\mu\text{s}$).

2.2 הגדרת רכיב Serial Setup ב-TSE

פרמטר ברכיב Serial Setup ערך מוגדר הסבר ומשמעות
Baud Rate 115200 (או 921600) קצב העברת הנתונים בסיביות לשניה. חייב להיות זהה להגדרת החיישן!
Data Bits 8 מספר סיביות הנתונים בכל בייט.
Parity None סיבית זוגיות (None / Even / Odd).
Stop Bits 1 מספר סיביות עצירה (Stop bits).

2.3 הגדרת רכיב Serial Receive ב-TSE

לשונית / פרמטר ב-Serial Receive ערך מוגדר הסבר ומשמעות
Execution Rate 100e-6 ($100\,\mu\text{s}$) תדר דגימה ועדכון של **$10\,\text{kHz}$** – מתאים בדיוק לתדר חוגי בקרת PMSM!
Start of Frame (SOF) [0xFF, 0xFF] (או []) תווי תחילת המסגרת (Header). אם אין Header רושמים [].
End of Frame (EOF) [0x0D, 0x0A] (או []) תווי סיום המסגרת (Tail). אם אין תו סיום רושמים [].
Status Port פורט יציאה אוטומטי מציג את מספר שגיאות הקליטה (Framing/Parity errors). במצב תקין מציג 0.

מפרט חלון Message Configuration (Generate Configuration):

שדה בחלון Configuration ערך מוגדר הסבר תפקודי
Signal Name raw_sensor_position שם המשתנה שיופק בפין היציאה של הבלוק ב-TSE
Signal Type Variable קריטי! יוצר פין יציאה פיזי על גבי הבלוק ב-Schematic Editor
Data Type Unsigned Integer סוג הנתונים של קוד המיקום (שלם חיובי 16-bit / 32-bit)
Length (bytes) 2 (או 4) אורך הנתונים בבייטים (2 בייטים = 16-bit, 4 בייטים = 32-bit)
Endian Big Endian / Little Endian סדר הבייטים במסגרת התקשורת (Big Endian מציב MSB ראשון)

שלב 3: חישובים מתמטיים וקוד C מלא לפענוח המיקום

המרת הקריאה הגולמית מהחיישן לזווית מכנית, זווית במעלות וזווית חשמלית עבור הבקרה.

שם הגודל המחושב נוסחה מתמטית הסבר ומשמעות
זווית מכנית ברדיאנים ($\theta_m$) $$\theta_m = \text{raw\_sensor\_position} \cdot \frac{2\pi}{65536}$$ הזווית הפיזית האמיתית של הציר ברדיאנים ($0 \dots 2\pi$)
מיקום במעלות ($Pos_{deg}$) $$Pos_{deg} = \theta_m \cdot \frac{180}{\pi}$$ המיקום במעלות ($0^\circ \dots 360^\circ$) המועבר לתצוגת מסך ב-SCADA
זווית חשמלית ברדיאנים ($\theta_e$) $$\theta_e = \text{mod}(p \cdot \theta_m, 2\pi)$$ הזווית החשמלית המוזנת לחוגי בקרת ה-FOC ולממיר ה-OEPC
💻 קוד C להעתקה לבלוק C-Function ב-Schematic Editor
/* 
   Typhoon HIL TSE - C Function: Position & Electrical Angle Decoder
   POLE_PAIRS: מספר זוגות הקטבים במנוע (לדוגמה 4 ב-QS100)
*/
#define PI 3.14159265358979323846
#define POLE_PAIRS 4

// 1. קבלת הקריאה הגולמית מבלוק ה-Serial Receive
unsigned int raw_count = in_raw_sensor_position;

// 2. חישוב זווית מכנית ברדיאנים (0 עד 2*PI עבור 16-bit sensor)
double theta_m = fmod((double)raw_count * (2.0 * PI / 65536.0), 2.0 * PI);
if (theta_m < 0) theta_m += 2.0 * PI;

// 3. המרה למעלות עבור תצוגת SCADA
double pos_deg = theta_m * (180.0 / PI);

// 4. חישוב זווית חשמלית עבור FOC וחוגי בקרת המנוע
double theta_e = fmod(POLE_PAIRS * theta_m, 2.0 * PI);
if (theta_e < 0) theta_e += 2.0 * PI;

// 5. השמת יציאות הבלוק ב-TSE
out_pos_deg = pos_deg;
out_theta_e = theta_e;

שלב 4: הגדרת מסך ותצוגה ב-HIL Control Center SCADA

הוספת ווידג'טים להצגת הזווית במעלות ומחוג מסתובב בזמן אמת.

📊 הווידג'טים להוספה במסך הפאנל (.cus)

  • Digital Display: מקשרים לאות Rotor_Position_deg. מציג זווית מדויקת (לדוגמה 142.85°).
  • Gauge (מד חוג מעגלי): הגדרת Min = 0, Max = 360. מציג מחוג מסתובב בזמן אמת.
  • Capture / Scope: אוסצילוסקופ המציג גרף רציף $Position(t)$ בזמן אמת.

⚡ סקריפט בדיקה ב-SCADA Log

# סקריפט פייתון ב-SCADA לקריאת המיקום בזמן אמת
pos = hil.read_analog_signal("Rotor_Position_deg")
printf(f"[SCADA Log] Rotor Position: {pos:.2f}°")

שלב 5: שילוב הזווית החשמלית ($\theta_e$) בחוגי בקרת המנוע

חיבור משוב המיקום שנקרא ב-TSE לחוגי בקרת ה-PMSM ודרייברי ה-OEPC.

סדר השילוב בלוק/חוג בקרה ב-TSE תפקיד ושימוש בזווית החשמלית ($\theta_e$)
1 Clarke & Park Transformation המזת זרמי הסטטור ($i_a, i_b, i_c$) לזרמי $i_d, i_q$ בעזרת זווית הרוטור החשמלית $\theta_e$
2 PI Current Controllers ($I_d, I_q$) בקרת הזרם והמומנט: שמירת $I_d = 0$ וויסות $I_q$ לפי דרישת המומנט
3 Speed & Position Outer Loop חוג סגור חיצוני המקבל את שגיאת המהירות $(\omega^* - \omega)$ ומפיק את זרם הייחוס $I_q^*$
4 OEPC Gate Generator (96 NOD) יצירת 8 אותות המיתוג (GS0..GS7) לממיר ה-OEPC בהתאם למתחי הייחוס ו-$\theta_e$
