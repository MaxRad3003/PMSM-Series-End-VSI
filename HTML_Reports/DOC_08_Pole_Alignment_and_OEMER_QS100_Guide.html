🎯 2. שיטות מציאת מיקום הקטבים ביחס לחיישן האבסולוטי (Pole Alignment)

במנוע PMSM, בקר ה-FOC חייב לדעת את הזווית החשמלית המדויקת של ציר השטף המגנטי של הרוטור ($d$-axis). הקשר מוגדר ע"י:

θe = (4 × θmech + θoffset) mod 2π

שיטה 1: נעילת ציר באמצעות זרם DC (מומלץ למעבדה)

  1. מכוונים ספק כוח DC לזרם בטוח של 1.5A עד 2A.
  2. מחברים הדק חיובי לפאזה U.
  3. מקצרים את פאזות V ו-W ומחברים להדק השלילי.
  4. הרוטור ננעל מכנית ב-θe = 0°.
  5. קוראים את הזווית מהאינקודר האבסולוטי: θread.
  6. מחשבים: θoffset = - (4 × θread).

💻 3. הטמעה במודל הסימולציה של Typhoon HIL

קוד ה-C-Function לחישוב הזווית החשמלית המכוילת ב-Typhoon HIL404:

#define POLE_PAIRS 2
#define TWO_PI (2.0 * 3.14159265358979323846)

// ערך ה-Offset שנמדד בניסוי הנעילה
#define THETA_OFFSET_DEG 57.15
#define THETA_OFFSET_RAD (THETA_OFFSET_DEG * (3.14159265358979323846 / 180.0))

// חישוב זווית חשמלית מדויקת ל-FOC
double theta_e = fmod(POLE_PAIRS * hires_rad + THETA_OFFSET_RAD, TWO_PI);
if (theta_e < 0.0) {
    theta_e += TWO_PI;
}
double theta_e_deg = theta_e * (180.0 / 3.14159265358979323846);
