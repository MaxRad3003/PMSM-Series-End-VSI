🔌 DOC 11: מדריך אינטגרציה וחיווט – Digilent Pmod RS485

מפרט חומרה מלא, תצורת Half-Duplex ל-HIPERFACE, חיווט 5V ל-Typhoon HIL404 והגדרת טרמינלים לאינקודר SICK SFM60.

🏠 פורטל ראשי
Digilent Pmod RS485 Analog Devices ADM2582E Supply: 3.0V – 5.5V (Native 5V) 2500V RMS Isolation Typhoon HIL404 Compatible

📌 1. סקירת המודול ומדוע הוא פותר את בעיית ה-2.5V?

כרטיס ה-Digilent Pmod RS485 הוא מודול תקשורת תעשייתי מבודד המבוסס על שבב Analog Devices ADM2582E (או ADM2587E).

⚡ עבודה טבעית ב-5V

הרכיב מקבל הזנת $5.0\text{V}$ ישירה ומייצר רמות לוגיות של $5\text{V}$ TTL/CMOS מלאות. אין עיוותי מתח ואין מחלקי מתח של 2.5V!

🛡️ עכבת מבוא אינסופית (High-Z)

כניסת ה-`TXD` (פין 2) היא כניסת שער CMOS טהורה ללא נגדי 10K פנימיים שמושכים מתח, מה שמאפשר ל-`DO1` של ה-HIL לרדת ל-$0.0\text{V}$ מושלם.

🔒 בידוד גלווני מלא (2500V RMS)

כולל ממיר DC-DC מבודד מובנה בטכנולוגיית isoPower® של Analog Devices להגנה מושלמת על ה-HIL404.

🔌 2. סכמת חיווט מלאה (HIL404 ↔ Pmod RS485 ↔ SICK SFM60)

┌────────────────────────┐         UART 5V (Direct CMOS)          ┌─────────────────┐
│                        │   Pin 2 (TXD)  ◄───────────────  DO1    │                 │
│  Digilent Pmod RS485   │   Pin 3 (RXD)  ───────────────►  DI1    │  Typhoon HIL404 │
│   (Analog Devices      │   Pin 5 (GND)  ◄───────────────► GND    │                 │
│      ADM2582E)         │   Pin 6 (VCC)  ◄───────────────  5V     │                 │
│                        │   Pin 1 & 4    (Jumper קצר יחד)         │                 │
└────────────────────────┘                                         └─────────────────┘
           │
           │  RS-485 Differential (Half-Duplex Jumper: A+Y, B+Z)
           ▼
┌────────────────────────┐
│      SICK SFM60        │
│      (HIPERFACE)       │
│  Pin 7 (Data+) <- A+Y  │
│  Pin 8 (Data-) <- B+Z  │
│  Pin 2 (GND)   <- GND  │
└────────────────────────┘

טבלת חיבורי מחבר J2 (צד ה-UART מול Typhoon HIL404):

פין במחבר Pmod J2 שם האות ב-Pmod פונקציה ב-Transceiver לאן לחבר ב-Typhoon HIL404? הערות חיווט
Pin 1 `~RE` Receiver Enable (Active Low) קצר (Jumper) לפין 4 (`DE`) מחבר את בקרת הכיוון יחד
Pin 2 `TXD` Driver Input (Transmit) Digital Output (DO1) שידור פקודות מה-HIL (0V / 5V)
Pin 3 `RXD` Receiver Output (Receive) Digital Input (DI1) קליטת תשובות מהאינקודר אל ה-HIL
Pin 4 `DE` Driver Enable (Active High) קצר (Jumper) לפין 1 (`~RE`) בקרת שידור/קליטה אוטומטית
Pin 5 `GND` Power Ground פין `GND` ב-DIO Header אדמה לוגית משותפת (0V)
Pin 6 `VCC` Power Supply (5.0V) פין `5V` ב-DIO Header הזנת 5.0V מלאה (VCC)

טבלת חיבורי טרמינל הברגים J1 (צד ה-RS485 מול אינקודר SICK SFM60):

הערת Half-Duplex קריטית עבור HIPERFACE:
פרוטוקול HIPERFACE משתמש בזוג חוטים דיפרנציאלי יחיד (Data+ / Data-) הן לשידור והן לקליטה (Half-Duplex).
בטרמינל ה-Pmod RS485 יש לקצר את A עם Y (Data+), ואת B עם Z (Data-).
הדק בטרמינל ה-Pmod אות Transceiver חיבור Half-Duplex פין וחוט באינקודר SICK SFM60 צבע חוט סטנדרטי ב-SICK
הדק `A` + הדק `Y` Rx Non-Inverting + Tx Non-Inverting קצר בין A ל-Y Pin 7 (Data +) אפור (Gray)
הדק `B` + הדק `Z` Rx Inverting + Tx Inverting קצר בין B ל-Z Pin 8 (Data -) ירוק (Green)
הדק `GND` Isolated RS-485 Bus Ground אדמה מבודדת Pin 2 (0V / GND) + Shield כחול (Blue) + סיכוך

🎛️ 3. הגדרת ג'מפר סיום קו (Jumper JP1 - Termination)

כרטיס ה-Pmod RS485 כולל ג'מפר בשם `JP1`:

  • כאשר הג'מפר `JP1` סגור (Loaded / Placed): מחובר נגד סיום קו של **$120\ \Omega$** בין קווי ה-RS-485. מומלץ להשאיר אותו סגור (ON) בחיבור הנקודתי מול האינקודר למניעת החזרות אות (Line Reflections).
