הושלמה בהצלחה מלאה אינטגרציית מערכת המשוב של אנקודר תעשייתי היברידי מסוג SICK SFM60 HIPERFACE אל סימולטור בזמן אמת Typhoon HIL 404. המערכת קוראת בו-זמנית הן את ערוץ הנתונים הטורי (RS-485) והן את ערוץ התהליך האנלוגי (Sin/Cos), ומספקת לולאת בקרה בתדר $f_s = 10\text{ kHz}$ ($\Delta t = 100\,\mu\text{s}$) בדיוק של מעל מיליון צעדים לסיבוב ($20\text{-Bit}$).

📐 3. מודל מתמטי ומשוואות פיענוח מיקום (LaTeX Formulation)

חבילת ה-32-Bit המתקבלת מהאנקודר ($pos\_raw$) מפוענחת לרכיב סיבוב בודד (Singleturn) ולמספר הסיבובים השלמים (Multiturn):

$$pos\_raw = (b_5 \ll 24) \mid (b_6 \ll 16) \mid (b_7 \ll 8) \mid b_8$$ $$\text{Singleturn Steps: } S_{\text{st}} = pos\_raw \text{ AND }\text{0x7FFF} \quad (0 \le S_{\text{st}} \le 32,767)$$ $$\text{Mechanical Angle (Coarse): } \theta_{\text{mech, coarse}} = \left( \frac{S_{\text{st}}}{32768.0} \right) \times 360.0^\circ$$ $$\text{Multiturn Turns Counter: } N_{\text{turns}} = (pos\_raw \gg 15) \text{ AND }\text{0xFFF} \quad (0 \le N_{\text{turns}} \le 4,095)$$ $$\text{Continuous Absolute Angle: } \theta_{\text{total}} = (N_{\text{turns}} \times 360.0^\circ) + \theta_{\text{mech, coarse}}$$

הזווית החשמלית ($\theta_e$) עבור מנוע סינכרוני בעל $P = 4$ זוגות קטבים:

$$\theta_e = \left( P \cdot \theta_{\text{mech}} \cdot \frac{\pi}{180^\circ} \right) \pmod{2\pi}, \quad \theta_e \in [0, 2\pi)\text{ rad}$$ $$\theta_{e,\text{deg}} = \theta_e \times \frac{180^\circ}{\pi} \in [0^\circ, 360^\circ)$$
🌊 4. ערוץ ה-Sin/Cos האנלוגי ואינטרפולציית 20-Bit (Process Channel)

א. ביטול רעשי אינוורטר ומתח ממוצע (Common-Mode Rejection & 2.5V Offset Cancellation):

$$V_{\text{sin, diff}} = V_{\text{AI1}} - V_{\text{AI2}} = (2.5\text{V} + 0.5\sin\theta) - (2.5\text{V} - 0.5\sin\theta) = 1.0 \cdot \sin\theta$$ $$V_{\text{cos, diff}} = V_{\text{AI3}} - V_{\text{AI4}} = (2.5\text{V} + 0.5\cos\theta) - (2.5\text{V} - 0.5\cos\theta) = 1.0 \cdot \cos\theta$$

ב. אינטרפולציה תוך-מחזורית ברזולוציית-על (Zero-Latency Fine Interpolation):

$$\theta_{\text{fine}} = \text{atan2}(V_{\text{sin, diff}},\, V_{\text{cos, diff}}) \in [0, 2\pi)$$ $$\theta_{\text{hires}} = \left( k_{\text{period}} + \frac{\theta_{\text{fine}}}{2\pi} \right) \times \frac{360.0^\circ}{1024}, \quad k_{\text{period}} \in [0, 1023]$$ $$\text{Total System Resolution: } 1,024 \times 1,024 = \mathbf{1,048,576\text{ counts/rev}} \; (20\text{-Bit})$$ $$\text{Angular Precision: } \Delta \theta = \frac{360^\circ}{1,048,576} \approx \mathbf{0.000343^\circ}$$
🧠 5. משערך מהירות PLL מסדר שני (2nd-Order Tracking Observer)

למניעת רעשי גזירה $\omega = \frac{\Delta \theta}{\Delta t}$, יושם משערך פאזה חוג סגור מסדר שני (Phase-Locked Loop Observer):

$$\text{Error: } e_{\theta}(k) = \theta_{\text{hires}}(k) - \hat{\theta}_{\text{pll}}(k)$$ $$\hat{\omega}_{\text{rad/s}}(k+1) = \hat{\omega}_{\text{rad/s}}(k) + \left( K_i \cdot e_{\theta}(k) \right) \Delta t$$ $$\hat{\theta}_{\text{pll}}(k+1) = \hat{\theta}_{\text{pll}}(k) + \left( \hat{\omega}_{\text{rad/s}}(k) + K_p \cdot e_{\theta}(k) \right) \Delta t$$ $$\text{Rotor Speed: } \hat{\omega}_{\text{RPM}} = \hat{\omega}_{\text{rad/s}} \times \left( \frac{60}{2\pi} \right)$$ $$\text{Tuning Parameters: } K_p = 800.0, \quad K_i = 40,000.0, \quad \Delta t = 100\,\mu\text{s} \implies \omega_n \approx 200\text{ rad/s}, \; \zeta = 1.0$$
📊 6. מערך הפיקוד והתצוגה ב-Typhoon HIL SCADA
רכיב ב-SCADA סיגנל מקושר יחידות משמעות הנדסית והתנהגות מאומתת
Phasor Graph (דיאגרמת מחוגים) out_pos_deg / mag_unit $\text{Polar Vector } (r, \theta)$ מחוג וקטורי מסתובב בזמן אמת במעגל פולארי $0^\circ \text{--} 360^\circ$ לפי כיוון הרוטור!
Mechanical Position out_pos_deg $\text{deg } (^\circ)$ זווית מכנית אבסולוטית במעלות ($0.0^\circ \text{--} 360.0^\circ$).
Hi-Res Position out_pos_hires $\text{deg } (^\circ)$ זווית באינטרפולציה אנלוגית ברזולוציה של $20\text{-bit}$ ($\gt 1,000,000$ צעדים).
Theta Electrical ($\theta_e$) out_theta_e $\text{rad}$ זווית חשמלית ל-4 זוגות קטבים ($0 \text{--} 2\pi$) לסגירת חוג בקרת FOC.
Rotor Speedometer out_speed_rpm $\text{RPM}$ מהירות סיבוב מסוננת ב-RPM מבוססת PLL (עומדת יציבה על $0.0\text{ RPM}$ במנוחה).
Multiturn Turns Counter checksum $\text{turns}$ מונה סיבובים שלמים שהמנוע ביצע ($0 \text{--} 4,095$ סיבובים מלאים).
