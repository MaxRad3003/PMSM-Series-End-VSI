סנכרון ומפרט מלא: פרוטוקול HIPERFACE® ו-Typhoon HIL 404

מדריך טכני RTL מעובד עבור קריאת מיקום מוחלט מאנקודרים מבית SICK AG

🔌 1. ארכיטקטורה היברידית (Hybrid Architecture)

פרוטוקול HIPERFACE® (מבוסס מפרט SICK im0064865) משלב שני ערוצי תקשורת מקבילים הפועלים בו-זמנית:

ערוץ תהליך אנלוגי (Process Channel)

  • אותות דיפרנציאליים אנלוגיים: +SIN, -SIN, +COS, -COS.
  • מתח נומינלי: 1 Vpp (תווח 0.8 Vpp עד 1.1 Vpp) עם אופסט ישר של כ-2.5V.
  • ללא השהייה (Zero Delay): משמש לסגירת חוגי מהירות ומיקום בזמן אמת בדרייבר.

ערוץ פרמטרים ספרתי (Parameter Channel)

  • תקשורת טורית בממשק דיפרנציאלי RS-485 (Data+ / Data-).
  • פורמט תווים: UART (1 Start, 8 Data, Parity, 1 Stop bit).
  • משמש לקריאת מיקום מוחלט, הגדרת נקודת אפס, וקריאת זיכרון EEPROM.

⚙️ 2. השכבה הפיזית והגדרות תזמון (Physical Layer)

פרמטרי התקשורת של ערוץ ה-RS-485 הטורי ב-HIPERFACE:

פרמטר ערך מוגדר / ברירת מחדל הערות הנדסיות
קצב שידור (Baud Rate) 9600 Baud (ברירת מחדל) ניתן להגדרה מ-600 Baud ועד 38,400 Baud.
ביטי נתונים (Data Bits) 8 Bits לוגיקת תווים רגילה ב-UART.
זוגיות (Parity) Even (זוגי) נדרש ב-HIPERFACE (ניתן לשנות ל-None/Odd במידת הצורך).
ביטי עצירה (Stop Bits) 1 Bit קבוע במפרט.
Timeout 55 / Baud Rate (~5.73 ms ב-9600) פסק זמן בין תווים לזיהוי סוף הפריים.

📦 3. מבנה הפריים ופקודת קריאת מיקום (Frame & Commands)

מבנה פריים תקני ב-HIPERFACE:

[ Address ] + [ Command ] + [ Data 0 ... Data n ] + [ XOR Checksum ]

פקודת קריאת מיקום (Read Position - Command 42h)

פניית ה-Master (Typhoon HIL 404) לקבלת מיקום מוחלט מורכבת מ-3 בייטים בדיוק:

בייט ערך Hex ערך עשרוני תיאור
בייט 1 (Address) 0x40 (או Broadcast 0xFF) 64 (או 255) כתובת ה-Slave (כתובת ברירת מחדל: Slave 0 = 40h).
בייט 2 (Command) 0x42 66 קוד פקודת קריאת המיקום המוחלט (Read Position).
בייט 3 (Checksum) 0x02 (או ב-Broadcast 0xBD) 2 (או 189) תוצאת פעולת XOR: 0x40 ^ 0x42 = 0x02.
תגובת האנקודר המוחזרת ל-HIL 404:
האנקודר מחזיר פריים של 7 בייטים: [0x40] [0x42] [Pos_Byte_3] [Pos_Byte_2] [Pos_Byte_1] [Pos_Byte_0] [Checksum].

🛠️ 4. סיכום חיווט והגדרות ב-Typhoon HIL 404 (RTL Formatted)

חיווט פיזי (Physical Wiring)

  • Gravity T (TXD) → Typhoon HIL DI 1 (קליטה ב-HIL)
  • Gravity R (RXD) → Typhoon HIL DO 1 (שידור מ-HIL)
  • Gravity + (VCC) → Typhoon HIL 5V
  • Gravity - (GND) → Typhoon HIL GND
  • Gravity A / B → Encoder DATA+ / DATA-
  • Gravity 12V / GND2 → Encoder +VDC / 0V

הגדרות הרכיבים ב-Schematic

  • Serial Setup: Access port: DIO, UART rx DI pin: 1, Baud: 9600, Parity: Even.
  • Initial Settings (Outputs): DO1 ממופה ל-HIL0 Serial Setup.uart tx data.
  • Serial Send1: Sending period: 10 ms, Start of frame: [0x40, 0x42], Constant payload: 2 (1 Byte), End of frame: [].
  • Serial Receive1: Start of frame: [0x40, 0x42], Variable: raw_sensor_position (4 Bytes).
