# Project Autonomous Execution Rules

## 🚀 Autonomous Execution Mode (מצב עבודה אוטונומי מלא)
- **Do NOT ask for permissions or approvals** before executing tasks, modifying code, creating files, running scripts, or executing shell commands.
- Proceed directly to implementation and verification without interruptions.
- Execute terminal commands, run simulations, rebuild presentations, update packages, and take verification screenshots autonomously.
- Report concise and clear progress/results upon completion.
