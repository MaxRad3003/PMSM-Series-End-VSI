מדריך עבודה מעשי עם Git & GitHub

כיצד לעבוד שוטף עם המאגר המקומי, לשמור גרסאות, לדחוף עדכונים לענן ולעדכן את פורטל המנחה ב-GitHub Pages באופן אוטומטי.
📂 מאגר GitHub הרשמי 🌐 אתר הפורטל החי (GitHub Pages) 📖 ספר הפרויקט ⚡ מצגת אינטראקטיבית
🧠

1. מה ההבדל בין Git ל-GitHub?

הרבה מתבלבלים, אך מדובר בשני דברים שונים המשלימים זה את זה:

💻 Git (תוכנה מקומית במחשב)

כלי לניהול גרסאות שרץ אצלך במחשב (קובץ .git בתיקייה). הוא זוכר כל שינוי שביצעת בקבצים, מאפשר לחזור אחורה בזמן, ומנהל נקודות ביקורת (Commits). הוא אינו תלוי ברשת.

☁️ GitHub (פלטפורמת ענן ואירוח)

שרת ענן בבעלות מיקרוסופט המארח את מאגר ה-Git שלך באינטרנט. הוא מאפשר גיבוי מרוחק, שיתוף עם המנחה, ומפעיל את שירות GitHub Pages שהופך את הקוד לאתר אינטרנט חי.

🔄

2. מחזור העבודה היומי (שמירה ופרסום ב-3 צעדים)

בכל פעם שערכת קוד, הוספת פרק בספר הפרויקט, או עדכנת שקף במצגת — כך מעבירים את השינויים לאתר החי של המנחה:

1
שינויים במחשב
Working Directory
git add .
←
2
שמירת גרסה מקומית
Local Commit
git commit -m "..."
←
3
דחיפה לענן
GitHub Remote
git push
←
LIVE
אתר פעיל
GitHub Pages
עדכון אוטומטי תוך 30 שנ'
שלב 1 • איסוף
בדיקה והוספת השינויים
רואים אילו קבצים שונו בעזרת git status, ומסמנים אותם לשמירה בעזרת git add.
# בדיקה מה השתנה
git status

# צירוף כל הקבצים שערכת
git add .
שלב 2 • תיעוד
יצירת נקודת שמירה (Commit)
יוצרים "קופסה סגורה" עם תיאור ברור של מה שנעשה (לדוגמה: עדכון שקף 10, הוספת פרק 4).
# שמירת גרסה עם תיאור
git commit -m "Update slide 10 and project book"
שלב 3 • פרסום
דחיפה לענן ול-GitHub Pages
מעלים את השינויים ל-GitHub. תוך 30 שניות האתר של המנחה מתעדכן אוטומטית!
# דחיפה לענן
git push
⚡
פקודת שורה אחת מהירה (One-Liner):
רוצים לשמור ולדחוף הכל בפקודה אחת? העתיקו והדביקו בטרמינל:
git add . && git commit -m "Update project" && git push
🚀

  • גישה ישירה לכל קובץ: כל קובץ שנמצא במאגר מקבל קישור ישיר על פי שמו. לדוגמה:

איך להוסיף את המשתמש השני שלך או שותף כמשתף (Collaborator)?

אם תרצה לערוך את המאגר גם מתוך החשבון maximr3003 בדפדפן:

  1. היכנס להגדרות המאגר: Settings → Collaborators
  2. לחץ על הכפתור הירוק Add people.
  3. חפש את maximr3003 (או את כתובת המייל שלו) ושלח הזמנה.
  4. פתח את חשבון maximr3003 בדפדפן ואשר את ההזמנה. מעתה שני החשבונות בעלי הרשאה מלאה!

5. טבלת פקודות Git שימושיות לשמירה

פעולה מבוקשת הפקודה להרצה העתקה
בדיקת סטטוס: מה שונה או נוסף git status
הוספת כל הקבצים: הכנה לשמירה git add .
שמירת גרסה (Commit): עם הערה git commit -m "הערה כאן"
דחיפה לענן: פרסום לאתר git push
משיכת עדכונים: אם ערכת מהדפדפן git pull
היסטוריית שמירות: צפייה ב-Commits git log --oneline -n 5
ביטול שינויים בקובץ: חזרה למצב הקודם git restore [filename]
🛡️

6. כללי זהב ובטיחות לעבודה עם GitHub

  • לא להעלות קבצים כבדים מעל 50MB-100MB: קבצי CAD ענקיים (SolidWorks 400MB) או קובצי Dump מוגדרים אצלנו ב-.gitignore כדי שלא יאטו או יחסמו את ה-GitHub Pages.
  • שמות קבצים באנגלית (ASCII): עבור קישורים באינטרנט, מומלץ שמות באנגלית כמו PMSM_Project_Book.html כדי למנוע בעיות של קידוד תווים עבריים בדפדפנים מסוימים.
  • אימות רענון בדפדפן (Hard Refresh): אם דחפת שינוי והאתר לא מציג אותו מיד, ייתכן שהדפדפן שומר זיכרון מטמון (Cache). לחץ על Ctrl + F5 (או Shift + F5) כדי לרענן בכוח.
